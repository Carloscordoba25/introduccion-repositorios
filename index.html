para crear un repositorio remoto en github, primero debes crear una cuenta en github y luego seguir estos pasos:

  1. Crear una cuenta en github
  2. Crear un nuevo repositorio en github
  3. Crear una carpeta local para el proyecto (en tu ordenador)
