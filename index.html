Repositorios en github

Repositorio remotos y locales

para crear un repositorio remoto en github, primero debes crear una cuenta en github y luego seguir estos pasos:

  1. Crear una cuenta en github
  2. Crear un nuevo repositorio en github
  3. Crear una carpeta local para el proyecto (en tu ordenador)

primer bloque

configuracion usuario y correo

  1. git config --global user.name "nombre"
  2. git config --global user.email "email@example.com"

segundo bloque

inicializar el repositorio local

  1. git init
  2. git add .
  3. git commit -m "mensaje de commit"

tercer bloque

comunicacion con el repositorio remoto

  1. git remote add origin https://github.com/usuario/nombre-repositorio.git
  2. git push -u origin master/main

para los repositorios ya creados solo se realizan los bloques dos y tres sin el remote add

Estados de archivos en repositorios

Los archivos en un repositorio pueden estar en diferentes estados:

  • U = Untracked: Archivos que no están siendo rastreados por Git.
  • M = Modified: Archivos que han sido modificados pero aún no se han agregado al área de preparación.
  • D = Deleted: Archivos que han sido eliminados.
  • A = Added: Archivos que han sido agregados al área de preparación.
  • S = Staged: Archivos que han sido agregados al área de preparación y están listos para ser confirmados.
  • C = Committed: Archivos que han sido confirmados en el repositorio local.
